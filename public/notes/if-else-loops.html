1. Conditions

A condition is an expression that is either true or false. It is built with comparison operators and combined with logical operators.

ComparisonMeaningLogicalMeaning
==equal to&&and: both must be true
!=not equal to||or: at least one is true
< >less than, greater than!not: flips true and false
<= >=at most, at least
  • = assigns a value; == compares. Writing if (x = 5) sets x to 5 and is always true.
  • Short-circuit: in a && b, if a is false then b is not checked. In a || b, if a is true then b is not checked. This makes if (b != 0 && a % b == 0) safe.
  • To check a range, write both sides: 1 <= x && x <= 10. The maths style 1 <= x <= 10 compiles but does something else.
  • When you mix && and ||, add brackets so the order is clear.

2. if, else if, else

The first condition that is true runs its block; the others are skipped. else runs when none was true.

#include <iostream>
using namespace std;

int main() {
    int marks = 82;
    if (marks >= 90) cout << "A\n";
    else if (marks >= 75) cout << "B\n";     // reached only if marks < 90
    else if (marks >= 50) cout << "C\n";
    else cout << "F\n";
    return 0;
}
B
  • Order matters: put the most specific check first. With marks >= 50 first, 82 would print C.
  • Use braces { } when a block has more than one statement. Without them, only the next statement belongs to the if.
  • Don't put a semicolon after the condition: if (x > 0); ends the if right there.

Ternary operator for a short either-or value: cout << (n % 2 == 0 ? "Even" : "Odd");

3. switch

switch compares one value with fixed cases. It works with int and char, not with decimals or strings.

switch (op) {               // op is a char such as '+'
    case '+': cout << a + b; break;
    case '-': cout << a - b; break;
    default:  cout << "Unknown operator";
}

Without break, execution falls through into the next case.

4. Loops

A loop repeats a block while a condition stays true.

#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) cout << i << " ";       // start; keep going while; step
    cout << "\n";

    int n = 37, steps = 0;
    while (n != 1) {                                      // repeat until a condition changes
        n = (n % 2 == 0) ? n / 2 : n + 1;
        steps++;
    }
    cout << steps << "\n";
    return 0;
}

The parts of a for loop are start (int i = 1), condition (i <= 5, checked before every round) and update (i++, done after every round).

5. break and continue

  • break leaves the loop immediately.
  • continue skips the rest of this round and goes to the next one.
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i % 3 == 0) continue;    // skip multiples of 3
        if (i > 7) break;            // stop completely after 7
        cout << i << " ";
    }
    cout << "\n";
    return 0;
}

6. Nested loops

A loop inside a loop. The inner loop runs completely for every round of the outer loop, so an outer loop of n rounds and an inner loop of m rounds do n × m steps. Patterns are the classic example: the outer loop picks the row, the inner loop prints that row.

#include <iostream>
using namespace std;

int main() {
    int n = 4;
    for (int row = 1; row <= n; row++) {
        for (int col = 1; col <= row; col++) cout << "*";
        cout << "\n";
    }
    return 0;
}

8. Handy tools

  • max(a, b) and min(a, b) (header <algorithm>) return the larger and smaller value, and can be nested: max(a, max(b, c)). Both values must have the same type.
  • abs(x) gives the value without its sign: abs(-7) is 7.
  • A string holds text: s.size() is its length and s[i] its i-th character, counting from 0.
  • Multiply instead of dividing in checks: a / b >= 0.4 is safer as a * 10 >= 4 * b. It avoids lost fractions and rounding errors.
#include <iostream>
#include <algorithm>
#include <string>
using namespace std;

int main() {
    int a = 4, b = -9, c = 7;
    cout << max(a, max(b, c)) << " " << min(a, min(b, c)) << "\n";
    cout << abs(b) << "\n";
    string s = "loop";
    cout << s.size() << " " << s[0] << s[3] << "\n";
    int marks = 38, total = 95;
    cout << (marks * 100 >= 40 * total ? "Pass" : "Fail") << "\n";   // is marks / total at least 40%?
    return 0;
}

9. Common mistakes

  1. Off by one: i < n runs n times starting from 0; i <= n runs n times starting from 1. Check the first and last value of i.
  2. Infinite loop: the update never makes the condition false, for example forgetting i++ in a while loop.
  3. = instead of == inside a condition.
  4. A stray semicolon: for (...); or if (...); gives the loop or if an empty body.
  5. Overflow in a running total: a sum of many numbers can pass 2 × 10^9; use long long.
  6. Forgetting break in a switch case.
  7. Changing the loop variable inside a for body, which makes the loop hard to follow and easy to break.
