1. What an array is

An array stores many values of the same type under one name, side by side in memory. Each value is reached by its index, its position counted from 0. An array of size n has indexes 0 to n − 1.

index01234
a[index]7-2949

a[0] is 7, a[4] is the last element, and a[5] doesn't exist.

2. Creating and reading an array

int a[5] = {7, -2, 9, 4, 9};      // fixed size, known while writing the code

int n;
cin >> n;
vector<int> v(n);                 // size chosen while the program runs (header <vector>)
for (int i = 0; i < n; i++) cin >> v[i];
  • A plain array's size must be a constant. When the size comes from the input, use a vector, or a plain array sized for the largest possible input (for n ≤ 1000, int a[1000];).
  • vector<int> v(n, 0); creates n zeros. v.size() is its length and v.push_back(x) adds x at the end.
  • A plain array declared inside a function starts with garbage values; one declared outside main (global) starts as all zeros. Write int cnt[26] = {0}; to zero a local array.
  • Very large arrays (over about 10^6 elements) belong outside main, where there is room for them.

3. Traversal: visiting every element

Traversal means walking the array once, usually from index 0 to n − 1, and doing something with each element.

#include <iostream>
using namespace std;

int main() {
    int a[5] = {7, -2, 9, 4, 9};
    int n = 5;
    for (int i = 0; i < n; i++) cout << a[i] << " ";        // forwards
    cout << "\n";
    for (int i = n - 1; i >= 0; i--) cout << a[i] << " ";   // backwards
    cout << "\n";
    return 0;
}
7 -2 9 4 9
9 4 9 -2 7

4. One pass, one thing to remember

Almost every traversal question is: walk the array once and keep track of one thing.

GoalWhat to rememberStart with
Sum or averagea running total0 (in long long)
Largest or smallestthe champion value, and its indexa[0] and index 0
Searchthe position found-1, meaning “not found”
Count with a testa counter0
 
#include <iostream>
using namespace std;

int main() {
    int a[] = {7, -2, 9, 4, 9};
    int n = 5;
    long long sum = 0;
    int best = a[0], pos = 0, evens = 0, where = -1;
    for (int i = 0; i < n; i++) {
        sum += a[i];                                       // running total
        if (a[i] > best) { best = a[i]; pos = i; }         // champion and its index
        if (a[i] % 2 == 0) evens++;                        // counter
        if (where == -1 && a[i] == 4) where = i;           // first position of 4
    }
    cout << sum << " " << best << " " << pos << " " << evens << " " << where << "\n";
    return 0;
}
27 9 2 2 3

The largest value 9 appears twice. > keeps the first one (index 2); >= would keep the last (index 4).

5. Indexes and positions

  • Indexes start at 0, but problems often number positions from 1. If they ask for a position, print index + 1.
  • The element before a[i] is a[i - 1], which exists only when i ≥ 1. The one after is a[i + 1], which exists only when i ≤ n − 2.
  • Reading or writing outside 0 to n − 1 is out of bounds. C++ doesn't stop you: you get garbage values, wrong answers or a crash.

6. Common mistakes

  1. Looping to i <= n, which reads a[n], one past the end.
  2. Starting the maximum at 0: if every value is negative, 0 wrongly wins. Start at a[0].
  3. Printing the index when the position was asked for, or the other way round.
  4. An int sum of many large values: 10^5 values of 10^9 need long long.
  5. Forgetting to zero a local array used for counting.
  6. Checking a[i - 1] at i = 0 or a[i + 1] at the last index.
