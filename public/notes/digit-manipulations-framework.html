1. Spot a digit question

If the problem talks about the digits of a number rather than its size, it is a digit question, and your first move is the % 10 / / 10 loop. Signal words:

  • “digit”, “digits of n”, “sum / product of digits”, “count digits”
  • “reverse the number”, “palindrome number”, “rotate the number”
  • Armstrong, happy, self-dividing, strong numbers
  • “repeatedly do X until a single digit remains”
  • “a number given as an array / string of digits” (Plus One, Add Strings)
  • “in base k”, “binary representation” (same idea, divide by k instead of 10)

2. Ask before you code

  1. Which order? Right to left → the template as it is. Left to right → reverse first, find the highest power of 10 (divisor method), or convert to a string.
  2. All the digits at once, or one at a time? One at a time (a running sum or count) needs O(1) space; storing them needs an array.
  3. Can the answer overflow? Reversing, multiplying, powers, factorials, building a new number → long long, or check before multiplying.
  4. Can n be 0 or negative? 0 never enters while (n > 0); a negative n gives negative digits in C++.
  5. Is there a maths shortcut (digital root, a divisibility rule, counting by position) that skips the loop?

Then save a copy if you need the original after the loop, and choose step 2 from the table below.

5. Test before you submit

Run every digit solution on: 0, a single digit, a negative number, a number ending in 0, a number containing a 0 digit, and INT_MAX / INT_MIN (or the largest allowed value).

Worked example

Problem: a number is self-dividing if every one of its digits divides it, and it has no 0 digit. Read n and print YES or NO. Limits: 1 ≤ n ≤ 10^9.

Spot it: “every one of its digits” → a digit question.

Order: any order works, so the plain template. One at a time: yes, a flag is enough, O(1) space.

Overflow: nothing grows, so int is enough. 0 or negative: n ≥ 1, so no special case.

Step 2: “is there a digit that fails?”, a flag that starts as true. A digit fails if it is 0 or doesn't divide n. Check 0 first, so we never compute n % 0.

Copy: every check needs the original n, so loop on a copy.

Test: 7 (one digit) → YES; 102 (has a 0) → NO; 128 → YES.

#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int temp = n;                 // work on a copy
    bool ok = true;
    while (temp > 0) {
        int digit = temp % 10;                                      // step 1
        if (digit == 0 || n % digit != 0) { ok = false; break; }    // step 2
        temp /= 10;                                                 // step 3
    }
    cout << (ok ? "YES" : "NO") << "\n";
    return 0;
}
