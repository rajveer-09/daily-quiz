The general idea

Walk the array once, from index 0 to n − 1, and decide what to remember while walking.

GoalRemember
Sum or averagea running total
Largest or smallestthe champion value (and its index)
Searcha found flag, or the position (−1 = not found)
Count with a testa counter
 
int n;
cin >> n;
vector<int> a(n);
for (int i = 0; i < n; i++) cin >> a[i];

for (int i = 0; i < n; i++) {
    // look at a[i], update what you remember
}

1. Largest or smallest element

You will see

  • The largest or smallest element, sometimes with its position.

Keep in mind

  • Start the champion at a[0], not 0. If all values are negative, 0 would wrongly win.
  • Indexes start at 0. If the problem wants positions from 1, print index + 1.
  • Ties: > keeps the first occurrence, >= keeps the last.
int best = a[0], pos = 0;
for (int i = 1; i < n; i++)
    if (a[i] > best) { best = a[i]; pos = i; }    // < for the smallest

2. Search for an element

You will see

  • Is x in the array? At which index? How many times?

Keep in mind

  • Decide what is needed: yes or no, the first index, the last index, or a count.
  • First index → break at the first match. Count → never break.
  • Use −1 for “not found”, and print the exact “not found” output the problem asks for.
int pos = -1;
for (int i = 0; i < n; i++)
    if (a[i] == x) { pos = i; break; }
if (pos == -1) cout << "No";
else           cout << "Yes";

3. Count elements with a property

You will see

  • Count the elements that are even, negative, in a range, or whose digits satisfy something (digit count, digit sum).

Keep in mind

  • This is two problems in one: (1) does one number pass the test? (2) count how many pass.
  • Solve the test for one number first (see Level 0 → If-Else and Loops → digits), try it on a few numbers, then put it inside the array loop.
  • Use a copy of each element for the digit loop, so the array isn't changed.

How to think

Outer loop = walk the array. Inner part = the one-number test. The counter goes up when the test passes.

int count = 0;
for (int i = 0; i < n; i++) {
    int t = abs(a[i]), digits = 0;
    if (t == 0) digits = 1;
    while (t > 0) { digits++; t /= 10; }
    if (/* test on digits */) count++;
}
cout << count;

Edge cases to test

Before you submit, run your code on each of these:

  • Only one element.
  • All elements equal.
  • All elements negative.
  • The target is missing.
  • The target is at the first index, at the last index, or repeated.
