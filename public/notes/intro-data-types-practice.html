1. Big Sum

Read two whole numbers a and b and print a + b.

Limits: 0 ≤ a, b ≤ 10^18

Input
1000000000000000000 1000000000000000000
Output
2000000000000000000
Hint

Does 10^18 fit in an int? Does 2 × 10^18 fit in a long long?

Solution

int holds only about 2.1 × 10^9. long long holds about 9.22 × 10^18, so even the sum fits.

#include <iostream>
using namespace std;

int main() {
    long long a, b;
    cin >> a >> b;
    cout << a + b << "\n";
    return 0;
}

2. Division Trap

Read two integers a and b. On the first line print a / b using integer division. On the second line print the exact result of the division.

Limits: −1000 ≤ a ≤ 1000, 1 ≤ b ≤ 1000

Input
7 2
Output
3
3.5
Input
-7 2
Output
-3
-3.5
Hint

Which way does integer division cut off the fraction for negative numbers? How do you make the computer keep the fraction?

Solution

int / int cuts the fraction off toward zero, so -7 / 2 is -3, not -4. Casting one side to double first gives the exact result.

#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a / b << "\n";
    cout << (double)a / b << "\n";
    return 0;
}

3. Shift the Letter

Read one lowercase letter. Print the letter that comes 3 places after it in the alphabet, wrapping around after z.

Limits: the input is one character from a to z

Input
a
Output
d
Input
x
Output
a
Hint

Turn the letter into a position from 0 to 25 with c - 'a'. How does % 26 help with the wrap-around?

Solution

Position = c - 'a'. Add 3, take % 26 so 26 becomes 0 again, then add 'a' to get back a letter.

#include <iostream>
using namespace std;

int main() {
    char c;
    cin >> c;
    char shifted = (c - 'a' + 3) % 26 + 'a';
    cout << shifted << "\n";
    return 0;
}

4. Negative Remainder

Read two integers a and b. On the first line print C++'s a % b. On the second line print the remainder as it is defined in maths, which is always between 0 and b − 1.

Limits: −10^9 ≤ a ≤ 10^9, 1 ≤ b ≤ 10^9

Input
-7 3
Output
-1
2
Input
7 3
Output
1
1
Hint

In C++, the remainder takes the sign of the first number. If it comes out negative, what can you add to make it fall between 0 and b − 1?

Solution

a % b is between −(b − 1) and b − 1. Adding b makes it positive, and a second % b brings a positive value back into range.

#include <iostream>
using namespace std;

int main() {
    long long a, b;
    cin >> a >> b;
    cout << a % b << "\n";
    cout << ((a % b) + b) % b << "\n";
    return 0;
}

The numbers are read as long long because (a % b) + b can reach about 2 × 10^9, which doesn't fit in an int.

5. Fits in 32 Bits

Read one integer n. Print YES if it fits in an int, otherwise NO.

Limits: −10^18 ≤ n ≤ 10^18

Input
2147483647
Output
YES
Input
2147483648
Output
NO
Input
-2147483648
Output
YES
Hint

You can't read a number that doesn't fit into an int variable. What type can hold every possible input? Which constants in <climits> give the range of int?

Solution

Read into long long so the value is stored correctly, then compare it with INT_MIN and INT_MAX.

#include <iostream>
#include <climits>
using namespace std;

int main() {
    long long n;
    cin >> n;
    if (n >= INT_MIN && n <= INT_MAX) cout << "YES\n";
    else cout << "NO\n";
    return 0;
}

6. Float Equality

Read three decimal numbers a, b and c. Print YES if a + b equals c (allowing a difference of up to 10^-6), otherwise NO.

Limits: −1000 ≤ a, b, c ≤ 1000, with up to 6 decimal places

Input
0.1 0.2 0.3
Output
YES
Input
1 2 4
Output
NO
Hint

Try printing 0.1 + 0.2 == 0.3. Why isn't it 1? What can you compare instead of the two values themselves?

Solution

Decimals are stored with tiny rounding errors, so 0.1 + 0.2 is not exactly 0.3 and == fails. Check that the difference is within the tolerance instead.

#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c;
    cin >> a >> b >> c;
    if (fabs((a + b) - c) <= 1e-6) cout << "YES\n";
    else cout << "NO\n";
    return 0;
}
