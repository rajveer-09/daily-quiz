1. Spot a GCD or LCM problem

Rule of thumb: the largest thing that fits into all → GCD. The smallest thing all fit into → LCM. Problems rarely say “gcd” out loud, so watch for these signals.

Limits hint: numbers up to 10^9 or 10^18 with a small count usually means one O(log) GCD per number, not looping over divisors.

2. Five steps for any GCD/LCM problem

  1. Spot it. Match the wording to a signal above. “Largest that fits all” (GCD) or “smallest all fit into” (LCM)?
  2. Translate to maths. Write the answer as a formula before coding:
    • largest d dividing every aᵢ → d = gcd(a₁, …, aₙ)
    • smallest t divisible by every aᵢ → t = lcm(a₁, …, aₙ)
    • is ax + by = c solvable? → c % gcd(a, b) == 0
  3. Transform it if it isn't direct.
    • Differences: gcd(a, b) = gcd(a, b − a), so look at aᵢ − a₀.
    • Invariant: subtract or mod operations never change the GCD.
    • Remove one element: a prefix GCD and a suffix GCD.
    • Counting: inclusion–exclusion with the LCM.
    • A huge LCM under a modulus: the larger exponent of each prime.
  4. Pick the tool: gcd / lcm, a loop over the array, prefix/suffix arrays, or extended Euclid.
  5. Guard the edges: overflow (divide before multiplying), zeros, negatives, n = 1, all numbers equal, a modulus. Test a tiny case by hand.

4. Extended Euclid

It finds x and y with a·x + b·y = gcd(a, b). You need it to actually solve ax + by = c, and for modular inverses.

#include <bits/stdc++.h>
using namespace std;

long long extGcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) { x = 1; y = 0; return a; }
    long long x1, y1;
    long long g = extGcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

int main() {
    long long x, y;
    long long g = extGcd(30, 12, x, y);
    cout << g << " " << x << " " << y << "\n";       // 30 * 1 + 12 * (-2) = 6
    return 0;
}

Worked example

Problem: find the largest k such that every aᵢ % k is the same. Print −1 if every k works. Limits: n ≤ 10^5, −10^9 ≤ aᵢ ≤ 10^9.

1. Spot: “same remainder mod k” → GCD of differences.

2. Translate: aᵢ % k == a₀ % k exactly when k divides aᵢ − a₀.

3. Transform: so k must divide every difference; the largest such k is the gcd of all |aᵢ − a₀|.

4. Tool: one loop with gcd, starting at 0.

5. Edges: if every number is equal, the GCD stays 0 and any k works, so print −1. Differences reach 2 × 10^9, so use long long.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto &x : a) cin >> x;
    long long g = 0;
    for (long long x : a) g = gcd(g, llabs(x - a[0]));
    cout << (g == 0 ? -1 : g) << "\n";
    return 0;
}
