1. Spot a prime or divisor question

Signal words in the statement:

  • “prime”, “composite”, “co-prime”, “prime factors”, “factorise”
  • “divisor”, “factor”, “divides”, “multiple”, “perfect number”
  • “count the primes up to N”, “primes in the range [L, R]”
  • “number of divisors”, “sum of divisors”, “exactly k divisors”
  • many queries on numbers up to 10^6 or 10^7 (a strong hint to precompute with a sieve)

2. Pick the tool from the limits

The two questions that decide everything: one number or many? and how large?

SituationToolTime
Divisors of one number, n up to about 10^12pair loop while d * d <= nO(√n)
Is one number prime? n up to about 10^12trial division up to √n, stop at the first divisorO(√n)
Many prime checks, or all primes up to N (N up to about 10^7)Sieve of Eratosthenes, onceO(N log log N), then O(1) per check
Factorise many numbers up to about 10^6smallest-prime-factor (SPF) sieveone sieve, then O(log x) per number
Divisor counts or sums for many numbers up to about 10^6for each i, visit its multiples (j += i)O(N log N), then O(1) per number
Rule of thumb: with q questions on numbers up to N, checking each one costs about q × √N. If that passes about 10^8, build a sieve up to N once instead.

3. Before you code

  1. Read the limits: the largest value, and how many numbers or queries.
  2. Pick the tool from the table above.
  3. Check the sieve's memory: a vector<bool> of 10^7 is about 1.25 MB, but an int array of 10^7 is 40 MB.
  4. Handle 0, 1 and 2 first: 0 and 1 are not prime; 2 is the only even prime.
  5. Watch overflow: write i * i <= n with long long i (or i <= n / i), never i <= sqrt(n).
  6. Size arrays n + 1 so index n exists.

4. Templates

#include <iostream>
#include <vector>
using namespace std;

bool isPrime(long long n) {                    // one number: O(sqrt n)
    if (n < 2) return false;
    for (long long i = 2; i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}

int countDivisors(long long n) {               // one number: O(sqrt n)
    int cnt = 0;
    for (long long d = 1; d * d <= n; d++)
        if (n % d == 0) cnt += (d == n / d) ? 1 : 2;   // a perfect square counts once
    return cnt;
}

vector<bool> sieve(int n) {                   // every number up to n: O(n log log n)
    vector<bool> p(n + 1, true);
    p[0] = false;
    if (n >= 1) p[1] = false;
    for (long long i = 2; i * i <= n; i++)
        if (p[i])
            for (long long j = i * i; j <= n; j += i) p[j] = false;
    return p;
}

int main() {
    cout << isPrime(97) << " " << isPrime(91) << " " << isPrime(1) << "\n";
    cout << countDivisors(36) << " " << countDivisors(1000000000000LL) << "\n";
    vector<bool> p = sieve(30);
    for (int i = 2; i <= 30; i++) if (p[i]) cout << i << " ";
    cout << "\n";
    return 0;
}

5. Test before you submit

Run every solution on: 0, 1, 2, a perfect square (36), a large prime (999983), a product of two large primes, and the largest allowed value.

Worked example

Problem: read q numbers and print YES if each is prime, otherwise NO. Limits: q ≤ 10^5, each number ≤ 10^6.

1. Limits: many numbers (10^5), each up to 10^6.

2. Tool: trial division would cost q × √N = 10^5 × 10^3 = 10^8 steps, which is borderline. A sieve up to 10^6 costs about 3 × 10^6 steps once, then each check is O(1). Use the sieve.

3. Memory: 10^6 bools, about 125 KB as a vector<bool>. Fine.

4. Edge cases: 1 → NO, 2 → YES.

#include <iostream>
#include <vector>
using namespace std;

const int MAX = 1000000;

int main() {
    vector<bool> isPrime(MAX + 1, true);
    isPrime[0] = isPrime[1] = false;
    for (long long i = 2; i * i <= MAX; i++)
        if (isPrime[i])
            for (long long j = i * i; j <= MAX; j += i) isPrime[j] = false;
    int q;
    cin >> q;
    while (q--) {
        int x;
        cin >> x;
        cout << (isPrime[x] ? "YES" : "NO") << "\n";
    }
    return 0;
}
