Hints

Try each problem first. Open a hint only when you are stuck.

1. Perfect Number

Loop i up to √n and add both i and n / i. Don't count n itself, and add a perfect-square divisor only once.

2. Four Divisors

Count the divisors with the √n loop. If the count is exactly 4, add their sum.

3. Count Primes

This is exactly the sieve from class. The only difference is that the problem asks for primes strictly less than n.

4. Closest Primes

Sieve up to right, then walk from left to right and compare each prime with the previous one.

5. Prime Pairs

Sieve up to n. For every x from 2 to n/2, check that isPrime[x] and isPrime[n - x] are both true.

6. SPF

Use the same loops as the sieve. Instead of false, store spf[j] = i when spf[j] is not set yet.

7. Counting Divisors

An O(√x) loop for each query is about 10^5 × 1000 = 10^8 operations, which is borderline. A faster way: for every i, add 1 to cnt[j] for each j = i, 2i, 3i, …. This works because of the same j += i idea from the sieve.
