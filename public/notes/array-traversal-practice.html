In every problem the first line is n, the number of elements, and the second line holds the n elements. Try each problem first; open the hint only when you are stuck.

1. Largest and Its Position

Print the largest element and its position, counting positions from 1. If the largest value appears more than once, print its first position.

Limits: 1 ≤ n ≤ 10^5, −10^9 ≤ a[i] ≤ 10^9

Input
5
7 -2 9 4 9
Output
9 3
Input
3
-5 -1 -8
Output
-1 2
Hint

What should the champion start as, if every value can be negative? Which comparison keeps the first of two equal values?

Solution

Start with a[0] at index 0. Replace only on a strictly larger value (>), so ties keep the first one. Print index + 1 for the position.

#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    long long best = a[0];
    int pos = 0;
    for (int i = 1; i < n; i++)
        if (a[i] > best) { best = a[i]; pos = i; }
    cout << best << " " << pos + 1 << "\n";
    return 0;
}

2. First Position

After the array, a third line holds a number x. Print the first position (from 1) where x appears, or -1 if it doesn't appear.

Limits: 1 ≤ n ≤ 10^5, −10^9 ≤ a[i], x ≤ 10^9

Input
6
4 8 15 16 8 42
8
Output
2
Input
3
1 2 3
7
Output
-1
Hint

Start the answer at −1. When should the loop stop?

Solution

Keep the position, starting at −1 for “not found”, and break at the first match so a later match can't overwrite it.

#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    long long x;
    cin >> x;
    int pos = -1;
    for (int i = 0; i < n; i++)
        if (a[i] == x) { pos = i + 1; break; }
    cout << pos << "\n";
    return 0;
}

3. Count in Range

After the array, a third line holds two numbers L and R. Print how many elements are between L and R, inclusive.

Limits: 1 ≤ n ≤ 10^5, −10^9 ≤ a[i] ≤ 10^9, L ≤ R

Input
7
3 10 -4 7 7 12 0
0 7
Output
4
Hint

“Inclusive” means the end values count. Which comparisons does that give?

Solution

A counter that goes up when L <= a[i] && a[i] <= R. Here 3, 7, 7 and 0 are in range.

#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    long long L, R;
    cin >> L >> R;
    int count = 0;
    for (int i = 0; i < n; i++)
        if (L <= a[i] && a[i] <= R) count++;
    cout << count << "\n";
    return 0;
}

4. Even Number of Digits

LeetCode 1295 · Find Numbers with Even Number of Digits

Print how many elements have an even number of digits. For example 12 (2 digits) and 7896 (4 digits) count; 345 and 7 don't.

Limits: 1 ≤ n ≤ 500, 1 ≤ a[i] ≤ 10^5

Input
5
12 345 2 6 7896
Output
2
Input
4
555 901 482 1771
Output
1
Hint

Two problems in one: first write a test for one number (how many digits does it have?), then count how many elements pass it.

Solution

The outer loop walks the array; the inner loop counts the digits of a copy of each element. The counter goes up when that count is even.

#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    int count = 0;
    for (int i = 0; i < n; i++) {
        int t = a[i], digits = 0;          // a copy, so the array isn't changed
        while (t > 0) { digits++; t /= 10; }
        if (digits % 2 == 0) count++;
    }
    cout << count << "\n";
    return 0;
}

5. Max Consecutive Ones

LeetCode 485 · Max Consecutive Ones

The array holds only 0s and 1s. Print the length of the longest run of 1s in a row.

Limits: 1 ≤ n ≤ 10^5, each a[i] is 0 or 1

Input
6
1 1 0 1 1 1
Output
3
Input
3
0 0 0
Output
0
Hint

Keep two things while walking: the length of the current run, and the best run so far. What should happen to the current run when you see a 0?

Solution

A counter that grows on every 1 and resets to 0 on every 0, plus a champion that remembers the largest value the counter ever reached. One pass, O(n) time, O(1) extra space.

#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    int run = 0, best = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] == 1) run++;
        else run = 0;                     // the run is broken
        if (run > best) best = run;
    }
    cout << best << "\n";
    return 0;
}

6. Second Largest

Print the second largest distinct value in the array, or -1 if there isn't one (every element is equal).

Limits: 1 ≤ n ≤ 10^5, 0 ≤ a[i] ≤ 10^9

Input
6
12 35 1 10 34 35
Output
34
Input
3
10 10 10
Output
-1
Hint

Keep two champions: the largest and the second largest. When a new value beats the largest, what happens to the old largest?

Solution

One pass with two values, both starting at −1 (every element is at least 0). A new largest pushes the old largest down to second. A value between them (and not equal to the largest) becomes the new second.

#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    long long first = -1, second = -1;
    for (int i = 0; i < n; i++) {
        if (a[i] > first) { second = first; first = a[i]; }
        else if (a[i] < first && a[i] > second) second = a[i];
    }
    cout << second << "\n";
    return 0;
}
