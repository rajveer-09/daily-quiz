1. Count the Digits

Read a non-negative integer n. Print how many digits it has.

Limits: 0 ≤ n ≤ 10^18

Input
4729
Output
4
Input
0
Output
1
Hint

Each round of the loop handles exactly one digit. What happens to while (n > 0) when n is 0?

Solution

Count how many times the loop runs; step 1 isn't even needed. 0 is handled separately because the loop never runs for it. O(log n) time, O(1) space.

#include <iostream>
using namespace std;

int countDigits(long long n) {
    if (n == 0) return 1;          // the loop won't run for 0
    int count = 0;
    while (n > 0) {
        count++;                   // step 2
        n = n / 10;                // step 3
    }
    return count;
}

int main() {
    long long n;
    cin >> n;
    cout << countDigits(n) << "\n";
    return 0;
}

2. Reverse Integer

LeetCode 7 · Reverse Integer

Read a 32-bit integer x. Print its digits reversed, keeping the sign. If the reversed value doesn't fit in a 32-bit int, print 0. Don't use long long.

Limits: −2,147,483,648 ≤ x ≤ 2,147,483,647

Input
-123
Output
-321
Input
120
Output
21
Input
1534236469
Output
0
Hint

In C++, -123 % 10 is -3, so the template already handles negatives if the loop runs while (x != 0). When must you check for overflow: before or after rev * 10?

Solution

Check before rev * 10: once it has overflowed, the value is already wrong. INT_MAX ends in 7 and INT_MIN in 8, which gives the last-digit checks. Dry run for −123: d = −3, rev = −3 → d = −2, rev = −32 → d = −1, rev = −321. O(log n) time, O(1) space.

#include <iostream>
#include <climits>
using namespace std;

int reverseInt(int x) {
    int rev = 0;
    while (x != 0) {
        int d = x % 10;            // negative digits for negative x
        x /= 10;
        if (rev > INT_MAX / 10 || (rev == INT_MAX / 10 && d > 7)) return 0;
        if (rev < INT_MIN / 10 || (rev == INT_MIN / 10 && d < -8)) return 0;
        rev = rev * 10 + d;
    }
    return rev;
}

int main() {
    int x;
    cin >> x;
    cout << reverseInt(x) << "\n";
    return 0;
}

3. Palindrome Number

LeetCode 9 · Palindrome Number

Read an integer x. Print YES if it reads the same forwards and backwards, otherwise NO. Don't convert it to a string.

Limits: −2,147,483,648 ≤ x ≤ 2,147,483,647

Input
12321
Output
YES
Input
-121
Output
NO
Input
10
Output
NO
Hint

Negative numbers and numbers ending in 0 (except 0 itself) can never be palindromes. Do you need to reverse the whole number, or is half enough?

Solution

Reverse only the back half: move digits from x to rev until rev catches up with x. For an odd number of digits, rev / 10 drops the middle digit. Reversing only half can't overflow and does half the work. Dry run for 12321: (x, rev) = (1232, 1) → (123, 12) → (12, 123); stop; 12 == 123 / 10 → YES. O(log n) time, O(1) space.

#include <iostream>
using namespace std;

bool isPalindrome(int x) {
    if (x < 0 || (x % 10 == 0 && x != 0)) return false;
    int rev = 0;
    while (x > rev) {              // reverse only half
        rev = rev * 10 + x % 10;
        x /= 10;
    }
    return x == rev || x == rev / 10;
}

int main() {
    int x;
    cin >> x;
    cout << (isPalindrome(x) ? "YES" : "NO") << "\n";
    return 0;
}

4. Armstrong Number

A k-digit number is an Armstrong number if the sum of its digits, each raised to the power k, equals the number itself: 153 = 1³ + 5³ + 3³. Read n and print YES or NO.

Limits: 0 ≤ n ≤ 10^9

Input
153
Output
YES
Input
123
Output
NO
Input
1634
Output
YES
Hint

You need k before you can add the powers, so count the digits first (problem 1). Then run the template again on a copy. Use an integer loop for the power, not pow().

Solution

Two passes: count the digits k, then add digit^k for every digit and compare with the original. The sum can pass INT_MAX for 10-digit inputs, so it is a long long. O(log n) time (the power loop runs at most 10 times), O(1) space. Others to test: 370, 371, 407.

#include <iostream>
using namespace std;

int countDigits(long long n) {
    if (n == 0) return 1;
    int count = 0;
    while (n > 0) { count++; n /= 10; }
    return count;
}

bool isArmstrong(long long n) {
    int k = countDigits(n);
    long long sum = 0, temp = n;   // work on a copy, keep n for the comparison
    while (temp > 0) {
        int digit = temp % 10;               // step 1
        long long power = 1;                 // step 2: digit^k with an integer loop
        for (int i = 0; i < k; i++) power *= digit;
        sum += power;
        temp /= 10;                          // step 3
    }
    return sum == n;
}

int main() {
    long long n;
    cin >> n;
    cout << (isArmstrong(n) ? "YES" : "NO") << "\n";
    return 0;
}

5. Strong Number

A number is a Strong number if the sum of the factorials of its digits equals the number itself: 145 = 1! + 4! + 5!. Read n and print YES or NO.

Limits: 1 ≤ n ≤ 10^9

Input
145
Output
YES
Input
123
Output
NO
Input
40585
Output
YES
Hint

Write a small factorial() helper (remember 0! = 1). Save the original before the loop.

Solution

For each digit, add factorial(digit) to the sum, then compare with the saved original. Digits are only 0–9, so you could also compute fact[0..9] once and look them up. Also test 1 and 2, which are Strong numbers.

#include <iostream>
using namespace std;

long long factorial(int x) {       // 0! = 1
    long long fact = 1;
    for (int i = 1; i <= x; i++) fact *= i;
    return fact;
}

bool isStrong(long long n) {
    long long original = n, sum = 0;   // save a copy
    while (n > 0) {
        int digit = n % 10;            // step 1
        sum += factorial(digit);       // step 2
        n /= 10;                       // step 3
    }
    return sum == original;
}

int main() {
    long long n;
    cin >> n;
    cout << (isStrong(n) ? "YES" : "NO") << "\n";
    return 0;
}

6. Add Digits

LeetCode 258 · Add Digits

Read n. Replace it with the sum of its digits, again and again, until a single digit is left. Print that digit.

Limits: 0 ≤ n ≤ 2,147,483,647

Input
38
Output
2
Input
0
Output
0
Hint

The loop version is the digit-sum template inside while (n >= 10). For an O(1) answer: what is n % 9 compared with its digit sum % 9?

Solution

38 → 3 + 8 = 11 → 1 + 1 = 2. Because n and its digit sum leave the same remainder when divided by 9, the answer is the digital root: 0 for n = 0, otherwise 1 + (n − 1) % 9. Here 1 + 37 % 9 = 2. Loop: O(log n); formula: O(1).

#include <iostream>
using namespace std;

int addDigits(int n) {
    while (n >= 10) {                  // repeat until one digit is left
        int sum = 0;
        for (int t = n; t > 0; t /= 10) sum += t % 10;
        n = sum;
    }
    return n;                          // same as: n == 0 ? 0 : 1 + (n - 1) % 9
}

int main() {
    int n;
    cin >> n;
    cout << addDigits(n) << "\n";
    return 0;
}

7. Happy Number

LeetCode 202 · Happy Number

Start with n and replace it with the sum of the squares of its digits, again and again. If this reaches 1, the number is happy; otherwise it loops forever. Print YES if n is happy, otherwise NO.

Limits: 1 ≤ n ≤ 2,147,483,647

Input
19
Output
YES
Input
2
Output
NO
Hint

Write next(x) = sum of the squares of the digits of x. A number that isn't happy falls into a cycle. How can you detect a cycle without storing every value?

Solution

19 → 1² + 9² = 82 → 68 → 100 → 1, so 19 is happy. Unhappy numbers fall into a cycle (it contains 4). Move a slow pointer one step and a fast pointer two steps (Floyd's cycle detection): they meet inside the cycle, or the fast one reaches 1. O(log n) time, O(1) space (O(log n) if you store the values in a set instead).

#include <iostream>
using namespace std;

int nextNum(int x) {                   // sum of squares of the digits
    int sum = 0;
    while (x > 0) {
        int d = x % 10;
        sum += d * d;
        x /= 10;
    }
    return sum;
}

bool isHappy(int n) {
    int slow = n, fast = nextNum(n);
    while (fast != 1 && slow != fast) {
        slow = nextNum(slow);
        fast = nextNum(nextNum(fast));
    }
    return fast == 1;
}

int main() {
    int n;
    cin >> n;
    cout << (isHappy(n) ? "YES" : "NO") << "\n";
    return 0;
}
