1. Middle Value

Read three integers. Print the middle one: the value that would sit in the middle if the three were sorted.

Limits: −10^9 ≤ each number ≤ 10^9 · Pattern: comparing a few values

Input
5 -2 9
Output
5
Input
3 3 1
Output
3
Hint

If you know the largest and the smallest, what is left over from the total?

Solution

Middle = total − largest − smallest. It works with equal values too. The total of three numbers up to 10^9 needs long long.

#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    long long a, b, c;
    cin >> a >> b >> c;
    long long hi = max(a, max(b, c));
    long long lo = min(a, min(b, c));
    cout << a + b + c - hi - lo << "\n";
    return 0;
}

2. Type of Triangle

LeetCode 3024 · Type of Triangle

Read the three side lengths of a triangle. If they can't form a triangle, print none. Otherwise print equilateral if all three sides are equal, isosceles if exactly two are equal, or scalene if all are different.

Limits: 1 ≤ each side ≤ 100 · Pattern: validate first, then classify

Input
3 3 3
Output
equilateral
Input
3 4 5
Output
scalene
Input
3 3 5
Output
isosceles
Input
1 2 3
Output
none
Hint

Three sides form a triangle only if every two of them add up to more than the third. Handle the invalid case first and stop. Then count how many of the three pairs are equal.

Solution

Validate first: if any two sides add up to no more than the third, it's none. Then (a == b) + (b == c) + (a == c) counts equal pairs: 3 means all equal, 1 means exactly two, 0 means all different. (2 is impossible: two equal pairs make the third equal too.)

#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    if (a + b <= c || a + c <= b || b + c <= a) {
        cout << "none\n";
        return 0;
    }
    int same = (a == b) + (b == c) + (a == c);
    if (same == 3) cout << "equilateral\n";
    else if (same == 1) cout << "isosceles\n";
    else cout << "scalene\n";
    return 0;
}

3. Grade Card

Read marks out of 100. Print the grade: A for 90 and above, B for 75 to 89, C for 50 to 74, and F below 50.

Limits: 0 ≤ marks ≤ 100 · Pattern: rule ladder

Input
82
Output
B
Input
50
Output
C
Hint

Check the highest grade first. Once marks >= 90 is false, what do you already know when you test marks >= 75?

Solution

An else if ladder from the top grade down. Each check only runs when every check above it was false, so each needs just one comparison. Test the boundaries: 90, 89, 75, 74, 50, 49.

#include <iostream>
using namespace std;

int main() {
    int marks;
    cin >> marks;
    if (marks >= 90) cout << "A\n";
    else if (marks >= 75) cout << "B\n";
    else if (marks >= 50) cout << "C\n";
    else cout << "F\n";
    return 0;
}

4. Pass Mark

Read a student's marks and the total marks of the exam. Print Pass if the marks are at least 40% of the total, otherwise Fail.

Limits: 1 ≤ total ≤ 10^9, 0 ≤ marks ≤ total · Pattern: formula check

Input
38 95
Output
Pass
Input
37 95
Output
Fail
Hint

38 / 95 is exactly 0.4. Can you write the check without dividing at all?

Solution

marks / total ≥ 40 / 100 is the same as marks × 100 ≥ 40 × total. No division means no lost fractions and no rounding errors. The products reach 10^11, so use long long.

#include <iostream>
using namespace std;

int main() {
    long long marks, total;
    cin >> marks >> total;
    if (marks * 100 >= 40 * total) cout << "Pass\n";
    else cout << "Fail\n";
    return 0;
}

5. FizzBuzz

LeetCode 412 · Fizz Buzz

Read n. For each number from 1 to n, print on its own line: FizzBuzz if it is divisible by both 3 and 5, Fizz if only by 3, Buzz if only by 5, otherwise the number itself.

Limits: 1 ≤ n ≤ 10^5 · Pattern: divisibility labels

Input
15
Output
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
Hint

Which case has to be checked first? Think about what happens to 15 if you check “divisible by 3” first.

Solution

The overlap (“both”) goes first, because 15 is also divisible by 3. Divisible by both 3 and 5 is the same as divisible by their LCM, 15.

#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        if (i % 15 == 0) cout << "FizzBuzz\n";
        else if (i % 3 == 0) cout << "Fizz\n";
        else if (i % 5 == 0) cout << "Buzz\n";
        else cout << i << "\n";
    }
    return 0;
}

6. Sum Multiples

LeetCode 2652 · Sum Multiples

Read n. Print the sum of all numbers from 1 to n that are divisible by 3, 5 or 7.

Limits: 1 ≤ n ≤ 10^3 · Pattern: accumulator with a condition

Input
7
Output
21
Input
10
Output
40
Hint

Visit every number from 1 to n. What should the sum start at? A number divisible by both 3 and 5 (like 15) must be added only once.

Solution

A loop over 1 to n with one condition joined by ||. Because it is one if, a number like 15 or 21 is added once, not twice. For n = 7: 3 + 5 + 6 + 7 = 21.

#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int sum = 0;
    for (int i = 1; i <= n; i++)
        if (i % 3 == 0 || i % 5 == 0 || i % 7 == 0) sum += i;
    cout << sum << "\n";
    return 0;
}

7. Digit Count and Sum

Read an integer n. Print how many digits it has and the sum of its digits, separated by a space. Ignore the minus sign.

Limits: −10^9 ≤ n ≤ 10^9 · Pattern: digits of a number

Input
4071
Output
4 12
Input
0
Output
1 0
Input
-305
Output
3 8
Hint

t % 10 is the last digit and t / 10 removes it. What happens to while (t > 0) when n is 0, or negative?

Solution

Take the absolute value first, peel off digits while t > 0, and handle 0 on its own (it has one digit, but the loop never runs).

#include <iostream>
#include <cstdlib>
using namespace std;

int main() {
    long long n;
    cin >> n;
    long long t = llabs(n);
    int count = 0, sum = 0;
    if (t == 0) count = 1;
    while (t > 0) {
        sum += t % 10;
        count++;
        t /= 10;
    }
    cout << count << " " << sum << "\n";
    return 0;
}
