1. Your first C++ program

A programming language is a language with fixed rules (syntax) for giving instructions to a computer. C++ code is compiled: a compiler (such as g++) translates it into machine code that the CPU runs.

#include <iostream>     // brings in cin and cout
using namespace std;     // lets us write cout instead of std::cout

int main() {             // every program starts running here
    cout << "Hello, world!" << "\n";
    return 0;            // 0 tells the system: finished without errors
}
Hello, world!

Other headers you will use: <cmath> (maths functions), <climits> (limits such as INT_MAX), <iomanip> (output formatting) and <string>. In competitive programming, #include <bits/stdc++.h> includes all of them at once (it works with g++ only).

Comments are ignored by the compiler: // one line or /* several lines */.

2. Output and input

cout prints with the insertion operator <<. cin reads with the extraction operator >>. Both can be chained.

int a, b, c;
cin >> a >> b >> c;              // input "10 20 30" or one number per line
cout << a + b + c << "\n";       // 60
  • cin >> skips spaces and newlines, and stops at the next space. To read a whole line with spaces, use getline(cin, s);
  • endl prints a newline and flushes the output. "\n" only prints a newline, so it is faster when printing many lines. Prefer "\n".
  • Every statement ends with a semicolon ;. There is no semicolon after #include lines or after a function's closing brace.

3. Variables and constants

A variable is a named box that holds a value of one type. A constant can't change after it is set; changing it is a compile error.

int count = 5;
count = 10;               // fine: variables can change
const int MAX = 100;      // MAX = 200; would not compile

Names may use letters, digits and _, can't start with a digit, can't be a keyword (int, for…), and are case-sensitive: sum and Sum are different variables. Always give a variable a value before reading it.

A char is stored as a number, its ASCII code. So you can do arithmetic on characters.

int main() {

Single quotes make one character: 'A' is a char. Double quotes make a string: "A" is text, stored as 'A' plus a hidden end marker '\0', so it takes 2 bytes.

6. Booleans

A bool holds true or false. Comparisons such as n % 2 == 0 produce a bool. cout prints true as 1 and false as 0; add boolalpha to print the words. Any non-zero number converts to true, and 0 to false.

#include <iostream>
using namespace std;

int main() {
    bool isEven = (10 % 2 == 0);
    cout << isEven << "\n";
    cout << boolalpha << isEven << "\n";
    int a = true, b = true;              // true is stored as 1
    cout << a + b << "\n";
    return 0;
}

7. Arithmetic traps: division and remainder

  • int / int gives an int: the fraction is cut off, toward zero. 7 / 2 is 3 and -7 / 2 is -3.
  • % gives the remainder and works on integers only. Its sign follows the first number: -7 % 3 is -1.
  • For a remainder that is never negative, use ((a % b) + b) % b.
#include <iostream>
using namespace std;

int main() {
    cout << 7 / 2 << " " << -7 / 2 << "\n";        // integer division
    cout << 7.0 / 2 << "\n";                       // one double makes it real division
    cout << -7 % 3 << " " << ((-7 % 3) + 3) % 3 << "\n";
    return 0;
}

8. Type casting

Type casting converts a value to another type.

  • Implicit (automatic): double d = 5; stores 5.0. In int + double, the int is promoted, so the result is a double.
  • Explicit (you ask for it): (double)a or the C++ style static_cast<double>(a).
  • Casting a decimal to int cuts off the fraction toward zero: (int)3.9 is 3 and (int)-3.9 is −3.
int a = 7, b = 2;
double avg = (double)a / b;    // 3.5: cast first, then divide
double bad = (double)(a / b);  // 3: the division already happened in int

9. Overflow

If a result doesn't fit its type, it overflows and the value is wrong. (For signed types this is undefined behaviour; in practice it usually wraps around to a strange number.)

The type of the result is decided by the operands, not by the variable you store it in:

int a = 100000, b = 100000;
long long wrong = a * b;          // overflows: the product is computed as int
long long right = 1LL * a * b;    // 10000000000: computed as long long

If inputs or products can go above about 2 × 10^9, read them into long long from the start.

10. Decimal numbers

Most decimals can't be stored exactly in binary. 0.1 + 0.2 is not exactly 0.3, so never compare decimals with ==. Check that the difference is tiny instead:

if (fabs(x - y) < 1e-9) { /* treat x and y as equal */ }    // fabs is in <cmath>

A literal like 6.753 is a double; 6.753f is a float. Storing 6.753 in a float loses digits, so a == 6.753 is false for float a = 6.753;

Printing and rounding (<cmath> and <iomanip>):

#include <iostream>
#include <cmath>
#include <iomanip>
using namespace std;

int main() {
    double x = 2.5;
    cout << floor(x) << " " << ceil(x) << " " << round(x) << "\n";   // down, up, nearest
    cout << round(-2.5) << "\n";                                     // halves go away from zero
    cout << fixed << setprecision(2) << 10.0 / 3 << "\n";            // exactly 2 decimals
    return 0;
}

11. Common mistakes

  1. Integer division by accident. (a + b + c) / 3 drops the fraction. Divide by 3.0.
  2. Overflow before storing. long long p = a * b; with int operands still overflows. Use 1LL * a * b.
  3. Comparing decimals with ==. Compare with a tolerance.
  4. Negative remainders. -7 % 3 is -1, not 2.
  5. Mixing up 'A' and "A". Single quotes for one character, double quotes for text.
  6. Reading a variable before giving it a value. Its value is garbage.
  7. Using endl in big loops. It flushes every time; "\n" is faster.
