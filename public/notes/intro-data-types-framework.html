The 5 checks

Most mistakes in beginner problems are not about logic. They come from the wrong type, a hidden overflow or an integer division. Run these five checks before you write code.

  1. Read the limits. What are the smallest and largest inputs? Are there decimals, negatives or characters?
  2. Pick the type for every value, including results in the middle of a calculation.
    • Whole numbers up to about 2 × 10^9: int.
    • Bigger, or a sum or product that can grow past that: long long.
    • Decimals: double.
  3. Look at every operation.
    • Multiplication or a large sum: can it overflow? Use long long or 1LL *.
    • Division: do you need the fraction? Make one side a double.
    • Remainder: can the number be negative?
  4. Characters: turn letters into positions with c - 'a' and digit characters into numbers with c - '0'. Work with the numbers, then convert back with (char).
  5. Match the output exactly: number of decimals (fixed << setprecision(k)), upper or lower case (YES or Yes), spaces and newlines.

Worked example

Problem: read three whole numbers, each between 1 and 10^9. Print their average with exactly 2 decimal places.

1. Limits: three numbers, each up to 10^9. The answer has decimals.

2. Types: each number fits in int, but their sum can reach 3 × 10^9, which does not. Read them as long long. The average is a double.

3. Operations: (a + b + c) / 3 is integer division and loses the fraction. Divide by 3.0.

4. Characters: none.

5. Output: exactly 2 decimals, so use fixed << setprecision(2).

#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    long long a, b, c;
    cin >> a >> b >> c;
    double avg = (a + b + c) / 3.0;
    cout << fixed << setprecision(2) << avg << "\n";
    return 0;
}

Output
