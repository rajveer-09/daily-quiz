1. Spot a fast-power problem

The problem says…Think
“aᵇ mod m”, “print the answer modulo 10⁹ + 7” with a huge exponentmodular fast power
“last digit” or “last k digits of aᵇ”fast power mod 10 or mod 10ᵏ
“number of ways” = k choices for each of n positionskⁿ mod m
a division, average or nCr under a prime modulusmodular inverse: b^(p−2)
an exponent that is itself a power (a^(b^c))Fermat: reduce the exponent mod p − 1
“apply the same step n times” with n up to 10^18 (Fibonacci, linear recurrences)matrix power

Limits hint: an exponent up to 10^9 or 10^18 rules out any loop that runs b times; you need O(log b).

2. Five steps

  1. Find the base, the exponent and the modulus. Write the answer as aᵇ mod m, or as a product of such powers.
  2. Reduce what you can: a %= m (fix a negative result). If m is prime and a isn't a multiple of m, the exponent can be reduced mod m − 1.
  3. Replace every division under a prime modulus with multiplication by the inverse, modPow(b, m - 2, m).
  4. Check overflow: m² must fit in a long long (m up to about 3 × 10^9). Use long long everywhere.
  5. Guard the edges: b = 0 gives 1, m = 1 gives 0, a = 0, a negative base, 0⁰ (usually defined as 1).

3. Template

long long modPow(long long a, long long b, long long m) {
    long long r = 1 % m;
    a %= m;
    if (a < 0) a += m;
    while (b > 0) {
        if (b & 1) r = r * a % m;
        a = a * a % m;
        b >>= 1;
    }
    return r;
}
// inverse of x mod a prime p:  modPow(x, p - 2, p)

Worked example

Problem: read a and b (0 ≤ a, b ≤ 10^18) and print the last digit of aᵇ. Take 0⁰ = 1.

1. Base, exponent, modulus: the last digit is aᵇ mod 10, so a, b and m = 10.

2. Reduce: only the last digit of a matters, so a %= 10. (10 isn't prime, so the exponent can't be reduced with Fermat; fast power handles 10^18 anyway.)

3. Divisions: none.

4. Overflow: m = 10, so every product is tiny.

5. Edges: b = 0 gives 1, even when a = 0. a = 0 with b > 0 gives 0.

#include <bits/stdc++.h>
using namespace std;

long long modPow(long long a, long long b, long long m) {
    long long r = 1 % m;
    a %= m;
    while (b > 0) {
        if (b & 1) r = r * a % m;
        a = a * a % m;
        b >>= 1;
    }
    return r;
}

int main() {
    long long a, b;
    cin >> a >> b;
    cout << modPow(a, b, 10) << "\n";
    return 0;
}
