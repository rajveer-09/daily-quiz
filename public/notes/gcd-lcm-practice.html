The problems go from a direct GCD to subarray GCDs, each adding one idea. Try each one first, and open the hint only when you are stuck.

1. GCD of an Array

LeetCode 1979 · Find Greatest Common Divisor of Array

Read n numbers. Print the GCD of the smallest and the largest of them.

Limits: 2 ≤ n ≤ 1000, 1 ≤ each number ≤ 1000 · Idea: direct GCD

Input
5
2 5 6 9 10
Output
2
Input
5
7 5 6 8 3
Output
1
Hint

Find the smallest and largest values in one pass, then call gcd once.

Solution

One pass for the minimum and maximum, then gcd(2, 10) = 2. O(n + log max).

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (auto &x : a) cin >> x;
    int lo = *min_element(a.begin(), a.end());
    int hi = *max_element(a.begin(), a.end());
    cout << gcd(lo, hi) << "\n";
    return 0;
}

2. Smallest Even Multiple

LeetCode 2413 · Smallest Even Multiple

Read n. Print the smallest positive number that is a multiple of both 2 and n.

Limits: 1 ≤ n ≤ 150 · Idea: direct LCM

Input
5
Output
10
Input
6
Output
6
Hint

“Smallest multiple of both” is the definition of the LCM.

Solution

The answer is lcm(2, n): n itself if n is even, otherwise 2n.

#include <bits/stdc++.h>
using namespace std;

int main() {
    long long n;
    cin >> n;
    cout << 2 / gcd(2LL, n) * n << "\n";      // lcm(2, n), dividing first
    return 0;
}

3. Count Multiples of a or b

Read N, a and b. Print how many numbers from 1 to N are divisible by a or by b.

Limits: 1 ≤ N, a, b ≤ 10^18 · Idea: LCM + inclusion–exclusion

Input
100 6 10
Output
23
Input
10 2 3
Output
7
Hint

N/a + N/b counts some numbers twice. Which ones? They are exactly the multiples of one number.

Solution

Numbers divisible by both are exactly the multiples of lcm(a, b), so subtract them once: N/a + N/b − N/lcm. For N = 100: 16 + 10 − 3 = 23. The LCM can pass 10^18 (and overflow); when a / gcd is already bigger than N / b, the LCM is bigger than N and there is nothing to subtract.

#include <bits/stdc++.h>
using namespace std;

int main() {
    long long N, a, b;
    cin >> N >> a >> b;
    long long both = 0, step = a / gcd(a, b);       // lcm = step * b
    if (step <= N / b) both = N / (step * b);       // only if the lcm fits under N
    cout << N / a + N / b - both << "\n";
    return 0;
}

4. Fox and Number Game

Codeforces 389A · Fox and Number Game

Read n numbers. Any number of times, you may pick xᵢ > xⱼ and set xᵢ = xᵢ − xⱼ. Print the smallest possible sum.

Limits: 2 ≤ n ≤ 100, 1 ≤ each number ≤ 100 · Idea: the GCD never changes

Input
3
2 4 6
Output
6
Input
5
45 12 27 30 18
Output
15
Hint

x − y is one step of Euclid's algorithm. What stays the same no matter which moves you make?

Solution

Subtracting never changes the GCD of the array, and every number can be driven down to that GCD. So the answer is n × gcd: 5 × 3 = 15.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long g = 0;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        g = gcd(g, x);
    }
    cout << g * n << "\n";
    return 0;
}

5. All Are Same

Codeforces 1593D1 · All are Same

Read n numbers. You choose a positive k and may subtract k from any number, any number of times. Print the largest k that can make all the numbers equal, or −1 if every k works.

Limits: 1 ≤ n ≤ 40, −10^6 ≤ each number ≤ 10^6 · Idea: GCD of differences

Input
6
1 5 3 1 1 5
Output
2
Input
4
100 -1000 -1000 -1000
Output
1100
Hint

Subtracting only makes numbers smaller, so they can all meet at the minimum. What must k divide?

Solution

Every number must come down to the minimum, so k must divide every aᵢ − min. The largest such k is the gcd of those differences. If they are all 0, every k works: −1.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto &x : a) cin >> x;
    long long mn = *min_element(a.begin(), a.end()), g = 0;
    for (long long x : a) g = gcd(g, x - mn);
    cout << (g == 0 ? -1 : g) << "\n";
    return 0;
}

6. Water and Jug

LeetCode 365 · Water and Jug Problem

You have jugs of x and y litres and unlimited water. In one move you can fill a jug completely, empty a jug completely, or pour from one jug into the other until the first is empty or the second is full. Read x, y and t, and print YES if the total water in both jugs can become exactly t litres, otherwise NO.

Limits: 1 ≤ x, y, t ≤ 10^3 · Idea: Bézout's identity

Input
3 5 4
Output
YES
Input
2 6 5
Output
NO
Hint

Let g = gcd(x, y). Filling gives x or y, emptying gives 0, and pouring moves an amount that is a multiple of g. What does that say about every total you can reach? What is the most water both jugs can hold?

Solution

Every jug always holds a multiple of g, so the total is a multiple of g, and it can't be more than x + y. Bézout's identity says every such amount can actually be reached. So the answer is yes exactly when t ≤ x + y and t % g == 0. For 3, 5, 4: fill 5, pour into 3 (5 → 2), empty 3, pour 2 across, fill 5, pour 1 across: 4 is left.

#include <bits/stdc++.h>
using namespace std;

int main() {
    long long x, y, t;
    cin >> x >> y >> t;
    bool ok = t <= x + y && t % gcd(x, y) == 0;
    cout << (ok ? "YES" : "NO") << "\n";
    return 0;
}

7. GCD on Blackboard

AtCoder ABC125 C · GCD on Blackboard

Read n numbers. You may replace one of them with any number you like. Print the largest possible GCD of all the numbers.

Limits: 2 ≤ n ≤ 10^5, 1 ≤ each number ≤ 10^9 · Idea: prefix + suffix GCD

Input
3
7 6 8
Output
2
Input
3
12 15 18
Output
6
Hint

Replacing one number with a copy of the others' GCD is the same as removing it. Can you find the GCD of “everything except index i” for every i without starting over each time?

Solution

pre[i] is the GCD of the first i numbers and suf[i] of the numbers from i to the end. The GCD without index i is gcd(pre[i − 1], suf[i + 1]). Two passes build them, one pass tries every i: O(n log max) instead of O(n²).

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto &x : a) cin >> x;
    vector<long long> pre(n + 1, 0), suf(n + 2, 0);
    for (int i = 1; i <= n; i++) pre[i] = gcd(pre[i - 1], a[i - 1]);
    for (int i = n; i >= 1; i--) suf[i] = gcd(suf[i + 1], a[i - 1]);
    long long best = 0;
    for (int i = 1; i <= n; i++) best = max(best, gcd(pre[i - 1], suf[i + 1]));
    cout << best << "\n";
    return 0;
}

8. Subarrays With GCD Equal to K

LeetCode 2447 · Number of Subarrays With GCD Equal to K

Read n and k, then n numbers. Print how many subarrays (contiguous parts) have a GCD equal to k.

Limits: 1 ≤ n ≤ 1000, 1 ≤ k, each number ≤ 10^9 · Idea: subarray GCD

Input
6 3
9 3 1 2 6 3
Output
4
Input
1 7
4
Output
0
Hint

Fix a start and extend to the right, keeping a running GCD. The GCD can only go down. When can you stop extending?

Solution

For each start i, extend j and keep g = gcd(g, a[j]). Count every time g == k. As soon as k no longer divides g, g can never come back to k, so stop. O(n² log max) in the worst case, and much faster in practice.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    long long k;
    cin >> n >> k;
    vector<long long> a(n);
    for (auto &x : a) cin >> x;
    long long count = 0;
    for (int i = 0; i < n; i++) {
        long long g = 0;
        for (int j = i; j < n; j++) {
            g = gcd(g, a[j]);
            if (g % k != 0) break;         // g only shrinks: it can never become k again
            if (g == k) count++;
        }
    }
    cout << count << "\n";
    return 0;
}
